# 需求确认单

最后更新：2026-10-19 18:12

## 产品目标

开发一款面向大学生的 Android 单词记忆 App。第一版由你本人使用，核心目标是跑通每日学习、听写、错题再练和定时复习闭环。

## 第一版范围

- 只支持 Android。
- 暂不登录、不连接自己的服务器、不做多设备同步。
- 单词、学习记录和错题保存在手机本地 SQLite 数据库。
- 用户按照 CSV 模板导入单词，CSV 至少包含单词、释义和音标。
- CSV 可选提供例句列；旧版三列 CSV 仍然兼容。
- 用户自行填写 DeepSeek API Key。
- 每日任务：设置数量、认识单词、使用 AI 例句选词填空、听写。
- 每日任务设置页支持设置每日新学单词数量和听力默认播放速度，数量可精确到个位。
- 选词填空和听写的单词顺序在各自环节内随机，任务进行中保持稳定。
- 认识单词页显示单词、翻译和音标，不显示例句。
- 翻译显示在单词和音标之间。
- 听写使用 Android 自带 TTS 朗读。
- 选词填空和听写错误都进入错题本。
- 错题再练完成后，用户手动移出已经掌握的单词。
- 用户可以清空当前导入的单词，但学习记录、学习天数、打卡和错题本记录必须保留。
- 清空后重新导入相同单词时沿用原学习记录，不把已学单词作为新词重复学习。
- 每日任务默认只选择当前启用且尚未学习的新单词。
- AI 只在设置页批量生成并缓存例句，学习任务运行时不需要联网。
- AI 不生成单词翻译，也不提供单词问答。
- 每完成一次每日任务，累计打卡次数加一。
- 第 3、6、9、12 次打卡后提醒复习。
- 复习可以选择最近多少天的单词，并省略观看释义环节。

## 暂不实现

- iPhone 版本
- 账号登录
- 云端数据库
- 多设备同步
- 管理后台
- 应用商店上架
- 社交、排行榜和会员付费
- 自动抓取外部词库

## 成功标准

1. Android 手机能安装并打开 App。
2. App 能导入符合格式的 CSV。
3. App 能保存 DeepSeek API Key 并调用 AI。
4. 用户能完成每日任务。
5. 错词能进入错题本并重新练习。
6. 打卡次数和复习提醒符合规则。
7. 关闭 App 后数据仍然存在。
8. 设置每日数量和听力默认速度后，关闭并重新打开 App 仍然生效。
9. 清空并重新导入相同单词后，学习记录、天数和错题记录不丢失，也不会重复作为新词学习。

## CSV 导入格式

### 文件要求

- 扩展名必须是 `.csv`。
- 编码使用 UTF-8。
- 第一行必须是列名。
- 每行代表一个单词。

推荐格式：

```csv
word,meaning,phonetic,example
```

兼容列名：

| 英文列名 | 中文列名 |
|---|---|
| `word` | `单词` |
| `meaning` | `释义`、`中文释义` |
| `phonetic` | `音标` |
| `example` | `sentence`、`例句` |

示例：

```csv
word,meaning,phonetic,example
abandon,放弃；抛弃,/əˈbændən/,They had to abandon the old plan.
benefit,好处；受益,/ˈbenɪfɪt/,Regular exercise can benefit your health.
```

### 校验规则

1. 缺少 `word`、`meaning` 或 `phonetic` 列时拒绝整个文件。
2. 单词和释义不能为空。
3. 音标列必须存在，但单元格可以留空。
4. 同一文件内重复单词，后面的行会被拒绝。
5. 已存在单词会更新释义和音标，并恢复为启用状态。
6. `example` 可选，旧版三列 CSV 继续兼容。
7. CSV 例句为空时保留已有例句；非空时覆盖并标记来源为 CSV。
8. 有问题的行跳过并返回行号与原因，不影响合法行。
