## 维护规则

1. 新信息优先补充到对应主文档，不新增重复的阶段状态页。
2. 阶段结束后只更新 `PHASE_HISTORY.md` 和 `CURRENT_HANDOFF.md`。
3. 所有文档的“最后更新”必须精确到分钟。
4. 删除或移动文档后，同步检查本索引和跨文档引用。
