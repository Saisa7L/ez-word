# 易词通 v1.0.0

首个正式 Android 版本，完成从词库导入、每日学习、错题复习到本地存档的完整闭环。

## 下载

- APK：`ez-word-v1.0.0.apk`
- APK 大小：114,608,476 B
- SHA-256：`86fb3418de092cdcfd8203254e461a61c57e2f241969e02313be25980347d6b1`
- MD5：`a7c338933829c249d0740ff2bedfb9dd`
- 最低 Android 版本：Android 7.0（API 24）
- 目标 Android 版本：Android 16（API 36）

## 本次更新

- 学习日改为本地时间凌晨 5 点切换，同一学习日多次完成任务不重复增加学习天数。
- 设置页改为按实际页面层级逐级返回，修复添加单词和当前词库直接返回“我的”的问题。
- 关于页启用检查更新，支持国内 `ghproxy.net` 镜像和 GitHub 回退。
- 支持在 App 内下载更新 APK，并打开 Android 系统安装器完成同签名覆盖安装。
- 存档、词库、错题、主题、个人资料和 AI 设置流程完成最终回归。

## 安装说明

- 从旧版覆盖安装时请勿卸载 App，现有 SQLite 数据会保留。
- 后续版本必须继续使用相同包名和签名密钥。
- Android 系统会要求用户确认安装未知来源应用，App 不会静默安装。
- 更新检查或下载失败时，可自行访问 GitHub Releases 获取安装包。

## 数据与隐私

- 核心数据保存在本机 SQLite。
- DeepSeek API Key 保存在 Android SecureStore，不进入存档。
- 检查更新和下载只在用户主动操作时联网。
- 更新 APK 下载到应用缓存，由 Android 系统继续校验包名和签名。

详细说明见仓库中的 `PRIVACY.md` 和 `SECURITY.md`。
