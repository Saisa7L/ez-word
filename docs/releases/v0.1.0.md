# 易词通 v0.1.0

首个面向 Android 的开源测试版本。

## 下载

- APK：`ez-word-v0.1.0.apk`
- SHA-256：`32543cc9dc563ac3ffbcbf80997f508c9bec4d7ec687d394a41fe4b4b164f294`
- 最低 Android 版本：Android 7.0（API 24）
- 目标 Android 版本：Android 16（API 36）

## 主要功能

- CSV 词库导入，支持中英文列名和可选例句。
- 每日任务：认识单词、选词填空、听力测试、完成记录。
- 错题本、错题回顾和单词再练。
- Android TTS 朗读和可调听力速度。
- 本地 SQLite 数据、JSON 存档导入导出和个人资料名片。
- 日间、夜间和自定义主题。
- 可选 DeepSeek API Key，用于补齐音标和例句。

## 安装说明

- 下载 APK 后在 Android 手机上允许当前文件来源安装应用。
- 后续版本必须使用相同包名和签名密钥覆盖安装，不要卸载应用后再升级。
- Expo Go 版本与本 APK 使用不同应用沙箱。如需保留 Expo Go 中的数据，请先导出 JSON 存档，再在正式 APK 中导入。
- 覆盖升级前建议继续导出一次存档作为额外备份。

## 数据与隐私

- 词库、学习记录、错题、设置和个人资料保存在本机 SQLite。
- DeepSeek API Key 保存在 Android SecureStore，不进入存档。
- 只有用户主动测试连接或生成单词数据时才会访问 DeepSeek。
- 本版本不包含账号登录、自建服务器、广告或行为分析。

详细说明见仓库中的 `PRIVACY.md` 和 `SECURITY.md`。

## 已知限制

- 仅支持 Android，不提供 iOS 或 Web 版本。
- 本版本未接入应用商店，仅通过 GitHub Releases 分发。
- Maestro/E2E 自动化、更多机型和真机性能采集仍在后续阶段完成。
- Android 系统备份策略和数据库额外加密仍需在后续发布硬化中确认。
