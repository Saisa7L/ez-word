# 主题颜色分类清单

最后更新：2026-10-19

## 使用说明

本文件用于人工确认每种颜色的最终归属。请直接修改“最终分类”列，或按编号回复。

| 标记 | 含义 |
|---|---|
| `T` | 主题色 |
| `B` | 背景色 |
| `F` | 固有色，不随主题变化 |
| `A` | 自动计算色，根据主题色或背景色推导 |
| `C` | 用户资料名片内的独立自定义色，不属于 App 主题 |

当前代码中的主题色对应 `colors.primary`，背景色对应 `colors.background`。

- 日间主题色为纯白 `#FFFFFF`，卡片白色，背景灰色
- 夜间主题色为 `#3D3D3D`，卡片灰色，背景黑色
- 自定义模式在日间模式基础上只修改主题色
- 首页“今日任务”和“我的 → 导入单词”的图标底板使用 `graySoft`，不参与自定义主题色推导
- 日间普通主操作按钮使用 `graySoft` 底板和 `accentText` 前景
- “开始导入”和任务退出确认弹层的“是”按钮使用品牌绿
- 听力测试进度条使用 `accentText`，日间黑色、夜间白色
