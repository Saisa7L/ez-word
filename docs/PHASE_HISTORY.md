## 关键决策

- 第一版单机运行，不使用自建服务器和云端同步。
- 学习任务运行时完全离线，DeepSeek 只在设置页批量生成例句。
- 词库清空是软停用，不删除单词和历史关联。
- 单词状态统一为未学习、已学习、错题。
- 错题回顾复用完整任务流程；单词再练跳过认识单词。
- 每日任务完成才增加学习天数，复习任务不增加学习天数。
- API Key 只保存在 Android 安全存储，不进入存档。
- P5 剩余视觉问题不再返工，P6 只做整理。
- P6 不包含 EAS、APK、签名和发布。
- P6 迁移 SQL 保持显式，以真实 SQLite 测试和运行时 schema 校验防止漂移。
- 所有导航动作必须经过统一入口；锁最小 300ms、最大 500ms。
- P2 工程化门禁统一通过 `npm run check` 执行，覆盖率阈值为 80%。
- Schema 清理属于独立高风险批次，不与格式或依赖整理混提。
