## 1. 产品定位

易词通（Ez Word）是一款面向国内 Android 用户的本地优先英语单词记忆 App。用户通过 CSV 导入个人词库，完成「认识单词 → 选词填空 → 听力测试 → 错题回顾 → 单词再练 → 本地存档」的单机学习闭环。v1.0.0 已通过正式签名 APK 发布（GitHub Releases + 国内镜像更新检查），当前处于稳定维护阶段；M1 结构重构（设置页拆分 + 页面流程下沉）已于 2026-11-17 完成。

## 2. 用户与角色

| 角色 | 谁 | 目标 | 权限/可见范围 | 限制 |
|---|---|---|---|---|
| 用户 | 国内 Android 用户（首版为开发者本人使用） | 每日背单词、听写、错题巩固 | 全部本机数据 | 无账号体系，数据不离开设备 |

单用户单机应用，无角色权限分层。所有业务数据保存在应用私有目录 SQLite。

## 7. 业务规则与边界

| ID | 规则 | 边界/例外 | 来源 |
|---|---|---|---|

| R2 | 选词填空/听写顺序在各自环节内随机，任务进行中保持稳定 | — | REQUIREMENTS |
| R3 | 填空与听写答错均入错题本 | 任务中途退出不写错题和学习记录，完成页统一结算 | REQUIREMENTS + ACCEPTANCE |
| R4 | 每日任务默认只选「当前启用且尚未学习」的新词 | — | REQUIREMENTS |
| R5 | 第 3/6/9/12 次打卡后提醒复习 | 复习可选最近 N 天单词，可省略观看释义环节 | REQUIREMENTS |
| R6 | 软清空保留学习记录、天数、打卡和错题历史；重导相同单词沿用原记录，不作为新词重复学习 | — | REQUIREMENTS |
| R7 | CSV 缺 word/meaning/phonetic 列整体拒绝；单词和释义非空；同文件重复词后行拒绝 | 音标列必须存在但单元格可空；坏行跳过并报行号 | REQUIREMENTS 校验规则 |
| R8 | 已存在单词导入时更新释义和音标并恢复启用；CSV 例句非空覆盖并标记来源，为空保留已有 | — | REQUIREMENTS 校验规则 |
| R9 | AI 只在设置页批量补齐缺失音标和例句；「覆盖已有」开关控制是否重新生成 | AI 不生成翻译、不做问答、不改单词和释义 | REQUIREMENTS |
| R10 | 任务运行时不需要联网 | — | REQUIREMENTS |
| R11 | API Key 存 Android SecureStore，不进 SQLite/存档/Git/日志 | 导出存档明确排除 | PROJECT_CONTEXT |
| R12 | 更新只信任本项目 GitHub Release 和 ghproxy.net 地址；下载后校验大小（有 MD5 则校验 MD5）；由 Android 系统安装器确认 | 清单校验失败提示用户自行访问 GitHub | ACCEPTANCE |
| R13 | 数据库迁移在单事务内按版本执行，列级幂等保护；迁移后 PRAGMA 校验字段，失败阻止启动 | — | DATABASE |
| R14 | 所有导航统一经 `utils/navigationActions`（带导航锁） | — | ARCHITECTURE |

| R16 | 正式 APK 必须同包名同签名覆盖安装 | — | PROJECT_CONTEXT 安全红线 |
| R17 | 资源受性能预算约束（HBC 6MB、资源总量 1MB、单资源 512KB、资源文件 24 个） | `npm run check:release` 校验 | DEVELOPMENT_GUIDE |

## 8. 核心流程摘要

详细流程、状态和异常在 `DESIGN.md`。这里只列：

| 流程 | 触发 | 成功结果 | 失败/异常 |
|---|---|---|---|
| CSV 导入 | 我的→导入单词 | 事务 upsert，返回新增/更新/跳过数 | 非法文件整体拒绝，坏行报行号 |
| 每日任务 | 首页→每日任务 | 完成页单事务写入错题/学习状态/完成记录 | 中途退出不写任何数据 |
| 错题回顾/再练 | 首页入口或错题本 | 回顾后自动移除答对错题；再练手动移除 | — |
| 存档导出/导入 | 我的→本地存档 | JSON 全量替换，主题和页面刷新 | 非法文件拒绝 |
| AI 补齐 | AI 设置页 | 批量写入缺失音标/例句 | 未配置 Key 时提示 |
| 检查更新 | 关于页 | 下载 APK → 系统安装器 | 镜像和 GitHub 均失败时提示自行访问 |
