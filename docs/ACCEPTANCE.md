## 更新功能验收

- 关于页检查更新可读取国内镜像清单。
- 无新版本时提示“已是最新版本”。
- 发现新版本时显示版本说明并允许下载。
- 下载过程显示进度，可取消。
- 下载后校验文件大小；清单包含 MD5 时同时校验 MD5。
- Expo Go 完成下载和校验后提示安装器需在正式 APK 中验收。
- 正式构建包含 `REQUEST_INSTALL_PACKAGES`，可调用 Android 系统安装器。
- 检查失败只提示用户自行访问 GitHub Releases。
