# v1.0.0 手动验收清单

最后更新：2026-10-22 20:36

## 使用方式

- 本次验收对象：`dist/release/ez-word-v0.1.0.apk`，SHA-256 `0c464c92c4a8115b4be0aa4c20089f164bc52cf983cbaa05bea0692c81925e09`。
- 按顺序执行；破坏性操作集中在词库、存档和 AI 部分，执行前先导出存档。
- 每项只记录“通过”或“失败”。失败时记录页面、操作步骤、预期结果、实际结果、是否必现。
- 不修改测试设备上的 App 数据，除非步骤明确要求。不要粘贴 API Key、签名文件或个人存档。

## 1. 安装、启动与持久化

- [ ] 覆盖安装当前 APK，确认原词库、错题、学习天数和个人资料保留。
- [ ] 冷启动进入首页，确认无崩溃、白屏或长时间加载。
- [ ] 关闭 App 后重新打开，确认首页统计、设置和主题保持。
- [ ] 将 App 切到后台再恢复，确认当前页面和任务状态正常。
- [ ] 检查应用未申请相机或麦克风权限。

## 2. 首页、Tab 与返回

- [ ] 首页显示今日已学、总计已学、错题本和学习天数，数值可正常读取。
- [ ] 底部“首页、错题本、我的”三个 Tab 可正常切换。
- [ ] 首页三个入口分别可进入“每日任务、错题回顾、单词再练”。
- [ ] 依次进入我的下七个页面并立即返回：个人资料、通用设置、主题外观、导入单词、本地存档、AI 设置、关于。
- [ ] 每个入口均返回“我的”，不出现空白页。
- [ ] 进入“导入单词 → 当前词库”，返回应回“导入单词”。
- [ ] 进入“当前词库 → 添加单词”，返回应回“当前词库”。
- [ ] 在“当前词库”再次返回应回“导入单词”，再返回才回“我的”。
- [ ] 用左上角返回和 Android 系统返回键各执行一次上述三级路径，结果应一致。
- [ ] 快速点击入口和快速连续返回，不重复跳页、不退出 App、不出现空白页。
- [ ] 弹窗打开时按 Android 返回，只关闭弹窗，不跳页、不写数据。

## 3. 每日任务完整流程

- [ ] 首页进入每日任务，显示可学习数量和“开始”。
- [ ] 开始后从认识单词页开始，单词、释义、音标显示正确，不显示例句。
- [ ] 认识单词页“上一个、下一个”可用，计数和进度同步。
- [ ] 点击发音可朗读单词；切到其他页面后朗读应停止。
- [ ] 长单词保持单行并自动缩小，不遮挡释义或音标。
- [ ] 最后一个单词按钮显示“开始填空”，只跳转一次。
- [ ] 在认识单词页返回，取消退出后仍停留原页；确认退出后回首页。
- [ ] 填空页可选中答案、替换答案、点击已填位置清空答案。
- [ ] 单词库分页、已使用状态和不可重复占用正常。
- [ ] 故意答错并确认，错误提示出现，错误项标红。
- [ ] 修改为正确答案后重新提交，红色状态清除。
- [ ] 全部填对后进入听力页，只跳转一次。
- [ ] 听力页首次播放速度与通用设置一致。
- [ ] 播放、暂停、继续、回退一个单词、倍速切换均正常。
- [ ] TTS 按顺序朗读全部单词，每词朗读两遍。
- [ ] 滚动输入和切换输入框时键盘不遮挡，输入内容和焦点不丢。
- [ ] 故意听写错误并确认，错误提示出现，错误项标红。
- [ ] 修改错误答案后红色状态立即清除。
- [ ] 听力页返回可取消退出；确认退出后回首页。
- [ ] 完成听力后进入完成页，学习单词数、错题数、时长显示正常。
- [ ] 完成页自动保存成功后才允许返回首页。
- [ ] 返回首页后学习天数、今日已学、总计已学和错题数按规则更新。
- [ ] 再次进入每日任务，上一轮答案和错误状态没有残留。
- [ ] 完成今天第一次每日任务后返回首页，学习天数增加一。
- [ ] 同一学习日再完成一次每日任务，学习天数不再增加，只增加完成次数。
- [ ] 条件允许时把系统时间调到 `04:59` 和 `05:00`，确认学习日按凌晨 5 点切换。

## 4. 任务数据边界

- [ ] 填空或听力答错后直接退出任务，不进入完成页；错题次数和学习状态不应改变。
- [ ] 只完成填空后在听力页退出，再次进入每日任务，可选新词集合不应因中途退出改变。
- [ ] 同一单词在填空和听力都答错，完成保存后错题次数只增加一次，来源同时包含两种题型。
- [ ] 快速连续点击“下一个、开始填空、提交”不会重复进入下一页。
- [ ] 等待超过导航锁时间后逐级返回，导航恢复正常。

## 5. 错题回顾与单词再练

- [ ] 首页进入错题回顾，显示抽题数量；“开始”可用。
- [ ] 错题回顾从认识单词开始，后续填空、听力、完成流程正常。
- [ ] 返回确认弹窗标题为“退出错题回顾？”。
- [ ] 开启自动移除正确错题后，完成一次正确回顾，正确单词从错题本移除。
- [ ] 回顾中仍答错的单词继续保留在错题本。
- [ ] 首页进入单词再练，可切换最近 7 天和全部范围。
- [ ] 单词再练直接进入填空页，不出现认识单词页。
- [ ] 单词再练完成页正常保存本次错题，不增加每日打卡。
- [ ] 返回确认弹窗标题为“退出单词再练？”。

## 6. 错题本

- [ ] 错题总数量、排序、单词、释义和来源显示正常。
- [ ] 每页最多 5 条，上一页、下一页和页码跳转正常。
- [ ] 跨页多选、取消选择和全选状态正常。
- [ ] 点击“移除”出现确认弹窗；取消不修改数据。
- [ ] 确认移除后当前页刷新、总数减少、单词状态同步。
- [ ] 进入“添加错题”，分页和跨页选择正常。
- [ ] 从当前词库选择单词加入错题，返回后总数增加。
- [ ] 手动输入已存在的词可加入；不存在的词给出明确提示。
- [ ] 已在错题本中的单词不出现在可选列表。
- [ ] 添加、移除后首页错题统计同步更新。

## 7. CSV 导入与当前词库

- [ ] 使用 `assets/templates/words-template.csv` 导入，新增数量正确。
- [ ] 再次导入相同文件，更新已有单词且不破坏学习记录。
- [ ] 导入中文列名 CSV，单词、释义、音标和例句识别正确。
- [ ] 导入缺少音标列的 CSV，整个文件被拒绝并提示原因。
- [ ] 导入部分非法行，合法行成功、非法行跳过并提示行号。
- [ ] 重复单词、空单词或空释义行被正确拒绝。
- [ ] 清空当前词库前出现确认；取消后数据不变。
- [ ] 确认清空后当前词库为空，但学习天数、记录和错题保留。
- [ ] 重新导入相同单词后恢复启用，已学单词不作为新词重复学习。
- [ ] 当前词库每页 5 条，跨页选择和分页正常。
- [ ] 批量修改学习状态后列表和筛选同步。
- [ ] 批量移除前出现确认；确认后当前词库数量减少，历史数据保留。
- [ ] 添加单词缺少单词、释义或音标时不能保存。
- [ ] 添加已启用单词时提示已存在；添加已停用单词时恢复原记录。
- [ ] “添加单词”保存后回到“当前词库”，不直接跳“我的”。

## 8. 本地存档

- [ ] 执行导出，生成文件名带 `.json`，系统文件选择器可完成保存。
- [ ] 取消导出文件选择，不出现崩溃或错误数据。
- [ ] 导出的存档不包含 DeepSeek API Key。
- [ ] 修改部分词库、设置、主题和错题后，导入刚导出的存档。
- [ ] 导入前显示确认；取消后数据不变。
- [ ] 确认导入后词库、学习记录、错题、设置、主题和个人资料完整恢复。
- [ ] “最近一次存档”的用户名、单词、学习记录、错题和完成记录摘要正确。
- [ ] 导入损坏 JSON、超大文件或缺少必需字段的文件，应拒绝且原数据不变。
- [ ] 导入资料中包含非法图片 URI 或孤儿引用的存档，应拒绝且原数据不变。

## 9. 通用设置与复习提醒

- [ ] 每日学习数量、听力速度、间隔、复习范围等可调整，边界按钮禁用正确。
- [ ] 开关状态可切换，说明文字与开关一致。
- [ ] 点击“保存设置”出现“保存成功”，关闭弹窗后设置生效。
- [ ] 退出并重新打开 App，设置值保持。
- [ ] 听力默认速度修改后，新任务首屏和播放速度使用新值。
- [ ] 当日打卡数达到复习提醒间隔时，回到首页出现“该复习了”应用内弹窗。
- [ ] 复习提醒“去复习、稍后”按钮可用，不使用系统通知。

## 10. 主题与个人资料

- [ ] 切换日间、夜间主题后，首页、Tab、任务页、表单和弹窗颜色正常。
- [ ] 保存主题后重启 App，主题保持。
- [ ] 自定义主题色可选择、取消、保存并立即应用。
- [ ] 自定义颜色输入非法值时给出提示，不写入错误颜色。
- [ ] 个人资料可修改用户名和简介，保存后首页与“我的”同步。
- [ ] 头像从相册选择、取消和更换均正常。
- [ ] 名片背景选择、更换、取消正常。
- [ ] 名片文字颜色和描边颜色、粗细可调整并保存。
- [ ] 名片图片导出成功，文件名带 `.png`，图片内容与当前名片一致。

## 11. AI 设置

- [ ] 输入自己的 DeepSeek API Key 后保存，界面只显示脱敏内容。
- [ ] 测试连接成功时提示成功；使用错误 Key 时提示失败，不崩溃。
- [ ] 清除 Key 时出现确认；取消保留，确认后清除。
- [ ] “覆盖已有单词数据”开关可切换，重启后保持。
- [ ] 无 Key 时点击生成，提示需要先配置 Key。
- [ ] 使用有效 Key 补齐缺失音标和例句，进度、成功和失败数量正常。
- [ ] 已存在字段在默认模式下不被覆盖；单词和中文释义始终不变。
- [ ] 开启覆盖模式后重新生成已有音标和例句，仍不修改单词和释义。
- [ ] 断网或服务失败时提示明确，未写入半成品数据。
- [ ] 导出存档后确认不包含 API Key。

- [ ] 进入“我的 → 关于”，检查更新显示“正在检查…”后给出结果。

- [ ] 系统安装器显示同包名覆盖安装，并保留原有数据。
- [ ] 取消系统安装后回到 App，不出现崩溃或数据变化。
- [ ] 无网络或两个下载源都不可用时提示失败，不安装不完整文件。
