| 技术 | 决定 |
|---|---|
| App | Expo + React Native + TypeScript |
| 路由 | Expo Router，页面放在 `src/app` |
| 本地数据库 | SQLite |
| 手机朗读 | Android 自带 TTS |
| AI | DeepSeek |
| API Key | 开发环境使用 Windows 用户环境变量，App 后续使用手机安全存储 |
| 服务器 | 第一版不使用 |
| UI | 用户使用 Figma 设计，再交给 AI 生成 |

## F1 已确认实现方式

- 三个基础页面使用 Mock 数据。
- 尚未开发的功能入口不处理点击。
- 图标库使用 Lucide，并安装 `lucide-react-native` 和 `react-native-svg`。
- 设计图中的文字和数字照搬。
- 首页绿色小恐龙是头像资源，不是吉祥物。

## 已确认的 UI 映射
