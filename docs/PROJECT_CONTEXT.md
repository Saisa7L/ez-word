## F1 已确认实现方式

- 三个基础页面使用 Mock 数据。
- 尚未开发的功能入口不处理点击。
- 图标库使用 Lucide，并安装 `lucide-react-native` 和 `react-native-svg`。
- 设计图中的文字和数字照搬。
- 首页绿色小恐龙是头像资源，不是吉祥物。

## 已确认的 UI 映射

- 今日任务进入每日任务流程。
- 错题回顾进入错题再练流程。
- 单词再练进入复习流程。
- A05 不显示例句，翻译位于单词和音标之间。
- A07 一次播放全部单词，播放细节在开发该页面时确认。
- 错题本允许从 CSV 已有单词中添加，也允许手动添加。
- 错题本每页设计图为 4 条，实际 UI 开发时改为 5 条。
