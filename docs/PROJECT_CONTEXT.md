## 技术栈

| 技术 | 决定 |
|---|---|
| App | Expo + React Native + TypeScript |
| 路由 | Expo Router，页面放在 `src/app` |
| 本地数据库 | SQLite |
| 手机朗读 | Android 自带 TTS |
| AI | DeepSeek |
| API Key | 开发环境使用 Windows 用户环境变量，App 后续使用手机安全存储 |
| 服务器 | 第一版不使用 |
| UI | 用户使用 Figma 设计，再交给 AI 生成 |
