# P6 代码与文档整理进度

最后更新：2026-10-19

## 当前状态

P6 尚未开始。P5 已按当前实现收口并提交。

## 阶段目标

P6 不新增业务功能，也不进行打包和发布。目标是把现有代码和文档整理到可以稳定接手、定位和维护的状态。

主要内容：

1. 整理代码：去重、删除失效代码、统一命名、拆分过长页面和重复样式。
2. 整理结构：明确页面、组件、业务功能、数据库、服务和工具层的职责边界。
3. 梳理数据流：页面入口、状态来源、SQLite 读写、主题 Provider、导入和存档恢复。
4. 整理文档：项目结构、页面清单、模块职责、数据库表、数据流和交接说明。
5. 保持自动检查通过。

## 建议顺序

| 顺序 | 工作 | 完成标志 |
|---|---|---|
| 1 | 生成代码结构清单 | 页面、组件、features、database、services 都有职责说明 |
| 2 | 梳理页面与状态数据流 | 主要流程能按“入口 → 状态 → 数据库 → 页面结果”追踪 |
| 3 | 整理重复代码和命名 | 明显重复的样式、格式化函数和组件用法有统一方案 |
| 4 | 整理数据库文档 | 表、迁移版本、读写仓库和存档关系可查 |
| 5 | 整理项目文档 | 根目录文档与实际代码结构一致 |
| 6 | 完整回归检查 | `npm run typecheck`、`npm run lint` 和 Android 离线导出通过 |

## 重点流程

- 首页统计与复习提醒
- 每日任务：认识单词 → 选词填空 → 听力 → 完成
- 错题本：查看、添加、移除、错题再练
- 单词再练与定时复习
- CSV 导入、词库管理和例句生成
- 主题模式、主题持久化和存档恢复
- 个人资料、名片图片和本地存档

## 代码重点目录

- `src/app`：Expo Router 页面和导航
- `src/components`：可复用 UI 和弹层
- `src/features`：业务流程和 Provider
- `src/database`：SQLite 建表、迁移和仓库
- `src/services`：TTS、DeepSeek、文件和安全存储
- `src/constants`：主题、资源和常量
- `src/hooks`：复用状态和交互逻辑
- `docs`：阶段状态、数据结构、页面地图和交接文档

## 阶段边界

- 不重新设计已经收口的 P5 主题 UI
- 不新增产品功能
- 不执行 EAS、APK、签名和发布
- 不进行大范围重写；优先小步整理并保持可运行
- 每次结构调整后运行类型检查和 lint

## 完成标志

- 代码目录和文档目录各有一份准确的职责说明
- 主要用户流程和 SQLite 数据流有文档可查
- 明显重复代码和失效引用完成整理
- `npm run typecheck` 通过
- `npm run lint` 通过
- Android 离线导出通过
