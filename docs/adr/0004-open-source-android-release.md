# ADR-0004 开源 Android 发布目标

- 状态：已接受
- 日期：2026-10-20

## 背景

项目已经具备完整学习闭环和较稳定的 Android 实现。下一阶段若继续只做内部重构，无法解决公开使用所需的仓库、签名、发布、文档和社区协作问题。

## 决策

最终产品目标调整为：

- 在 GitHub 以开源方式发布源码。
- 面向国内 Android 用户。
- 通过 GitHub Releases 提供签名 APK。
- 保持可维护和可扩展，但第一阶段不追求跨平台。
- 多语言、多平台和更多功能在稳定版本之后评估。

## 后果

- 当前优先级从继续扩展功能转为发布硬化。
- 正式 APK、签名、升级兼容、隐私说明和社区文档成为发布阻塞项。
- Expo Go 验收不能替代 APK 安装和覆盖升级验收。
- 后续功能必须继续保持模块边界和兼容测试。

## 替代方案

- 直接上应用商店：当前团队和发布流程未准备，先采用 GitHub Releases。
- 立即支持 Web/iOS：原生能力差异过大，会显著扩大范围。
- 继续只做内部重构：不能形成可公开使用的产品。
