# ADR-0003 规范化数据模型

- 状态：已接受
- 日期：2026-10-20

## 背景

旧模型把任务、复习、AI、主题设置放在单张 `app_settings`，将错题来源存为逗号字符串，并保留未使用的 `learned_count`。这些结构增加迁移、查询和存档维护成本。

## 决策

数据库分三版演进：

- v19：拆分 `task_settings`、`review_settings`、`ai_settings`、`theme_settings`。
- v20：错题来源迁移到 `wrong_book_sources` 关联表。
- v21：删除 `word_learning_state.learned_count`，保留首次和最近学习时间。

旧存档在解析时转换为当前结构；未识别或已废弃字段被安全忽略。

## 后果

- 所有设置写入必须使用对应设置表。
- 错题来源使用强类型来源集合，不再拼接逗号字符串。
- 旧数据库和旧存档需要持续保留兼容测试。
- 存档字段变化必须同步 schema、旧版本转换和恢复测试。

## 替代方案

- 保持宽表并仅停止写入：死列继续增加迁移和存档复杂度，已否决。
- 一次性完成所有迁移：风险不可控，改为按版本分批。
