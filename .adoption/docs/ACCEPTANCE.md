## 5. 回归重点

- 覆盖安装后 SQLite 数据、任务设置、主题和个人资料保持。
- 同一学习日多次完成任务不重复增加学习天数（5 点边界）。
- 软清空重导：学习记录、天数、错题不丢失且不重复学。
- 存档 round-trip 排除 API Key；非法存档拒绝。
- 更新清单只接受 GitHub Release 与 ghproxy.net 地址；APK 大小/MD5 双校验。
- 每日任务中途退出零写入；完成页单事务结算。

## 6. 非功能检查

- 性能：资源总量 ~0.78MB（预算 1MB）；HBC <6MB；性能预算门禁通过。
- 安全/隐私：API Key 仅 SecureStore；日志脱敏；见 PRIVACY.md。
- 无障碍：TalkBack、大字号、对比度、减少动画适配，accessibility.test.ts。
- 兼容性：存档 v10-v21；不支持 v11（显式报错）。
- 离线/弱网：核心流程全离线；更新下载可取消。
